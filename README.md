شروع ذكاء اصطناعي وتعلم عميق (Deep Learning) يهدف إلى الكشف عن مرض اعتام العين (Cataract) من خلال تحليل الصور الطبية للعين. يساعد هذا النظام في التشخيص المبكر وتقديم الدعم للأطباء والمختصين.
📌 نظرة عامة
تم تطوير هذا المشروع باستخدام تقنيات الرؤية الحاسوبية (Computer Vision) والشبكات العصبية التلافيفية (CNN) لتصنيف صور العين إلى فئتين: (مصاب باعتام العين / سليم). المشروع مخصص للأغراض التعليمية والبحثية.
📊 البيانات (Dataset)
نظراً للحجم الكبير لملفات البيانات، لم يتم رفع الداتاسيت إلى هذا المستودع. يحتوي هذا المستودع على الكود المصدري لتدريب المودل وتقييمه.
🧠 التقنيات وهيكلية المودل (Tech Stack)
اللغة: Python
المكتبات: TensorFlow / Keras, NumPy, Pandas, Matplotlib, OpenCV
الخوارزمية: Convolutional Neural Network (CNN)
نوع المشكلة: تصنيف صور طبية (Medical Image Classification)
المقاييس المستخدمة: Accuracy, Precision, Recall, F1-Score
